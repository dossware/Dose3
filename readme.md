### To install

Linux,MacOS
```
curl -fsSL https://dose3.dossware.com/install.sh | sh
```
Windows
```
irm https://dose3.dossware.com/install.ps1 | iex
```

## Script

```
dose -v  ----> check version
dose update  ----> update version
dose scan  ----> scan runing port
dose kill <YOUR PORT> ----> kill port
dose ----> start new project
```
